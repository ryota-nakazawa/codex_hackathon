# セキュリティチェックエージェントメモ

## 実装済みの基本対策

- 永続保存なし
- レスポンスに `no-store`
- `CSP`, `X-Frame-Options`, `nosniff`, `Referrer-Policy`, `Permissions-Policy`
- 入力サイズ制限
- 画像サイズ制限
- 同一オリジン制約
- 簡易レート制限
- パストラバーサル防止
- リクエスト本文のログ非出力

## 残るリスク

- PoC のため認証は未実装
- `live` モード利用時は外部 API 送信可否の院内ルール整備が必要
- 画像とテキストの完全匿名化は運用で担保が必要
- in-memory レート制限は単一プロセス前提

## 本番前に追加すべき項目

- SSO または院内認証
- 監査ログとアクセス制御
- 秘匿情報マスキング
- 閉域/プロキシ構成の明文化
- 外部送信の同意フロー
